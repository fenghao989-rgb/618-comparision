# 618比价助手 - 浏览器扩展

## 功能介绍

这个浏览器扩展可以自动获取淘宝、天猫、京东、拼多多、苏宁等电商平台的商品价格，并一键同步到比价网页进行对比。

## 安装步骤

### 1. 下载扩展文件

将 `browser-extension` 文件夹复制到您的电脑中。

### 2. 在Chrome中加载扩展

1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 开启右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择 `browser-extension` 文件夹

### 3. 开始使用

1. 打开比价网页 (http://localhost:8080 或您的部署地址)
2. 访问电商平台的商品页面（如京东商品页）
3. 点击浏览器右上角的扩展图标
4. 扩展会自动获取当前商品的价格
5. 点击「打开比价网页」，价格会自动同步

## 支持的平台

- 🛒 淘宝
- 🏪 天猫
- 📦 京东
- 💰 拼多多
- 📺 苏宁
- 🏬 有赞

## 工作原理

1. **Content Script**: 在电商平台页面自动执行，提取商品价格信息
2. **Background Script**: 管理数据存储和消息传递
3. **Popup**: 提供用户界面，显示已获取的价格

## 数据同步

扩展获取的价格数据会：
- 存储在浏览器本地 (chrome.storage.local)
- 通过 localStorage 同步到比价网页
- 30分钟内有效

## 注意事项

1. 某些页面可能因为反爬机制无法获取价格
2. 价格数据仅供参考，实际价格以平台为准
3. 如果扩展无法获取价格，可以手动输入
